# Contributing

This repository is maintained as a small demo project for practicing backend and release workflows.

## Pull requests

Pull requests are welcome but not expected. If you want to open a PR:

- keep the scope small and focused;
- describe the change and how you tested it;
- follow the existing GitFlow-style branching (feature/..., bugfix/...).

For larger changes, please open an issue first to discuss the direction.

## Coding style

- follow the existing project structure (handlers, services, repositories, models);
- keep tests and scripts up to date when changing behavior;
- prefer small, readable commits over large, mixed ones.
