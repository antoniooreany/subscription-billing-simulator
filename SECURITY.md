# Security Policy

This project is maintained as a small demo and learning repository.

Even though this is not a production system, please report any security-related issues privately so they are not disclosed before a fix is available.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please contact me by email.

- Contact: anton.gorshkov (at) example.com
- Please include: a short description, steps to reproduce, and any relevant logs

I will review the report on a best-effort basis and decide whether it requires a fix or documentation update.
